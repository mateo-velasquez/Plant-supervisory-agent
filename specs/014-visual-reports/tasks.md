- **mypy and pytest per commit.** A commit's tests use only symbols from that commit or earlier, so each commit passes `mypy --strict` over `src tests evals` and `pytest` on its own. Write each task's new files only in that task (the pre-commit mypy hook leaves untracked files in place).
