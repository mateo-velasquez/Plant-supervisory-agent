# 008 · Cited cause and logbook escalation — Tasks

Ordered, test-first. Each task is one commit, and **each task is committed before the next one starts**: the pre-commit mypy hook stashes unstaged changes to tracked files but leaves untracked files on disk, so new files of a later task would be type-checked with an earlier commit. A commit's tests reference only symbols introduced in that commit or earlier, and every tracked `src/` change they rely on is in the same commit. The hook runs mypy only, so **each task also runs `uv run pytest` (and ruff) before committing**. Owner: tests by `test-writer`, code by `domain-implementer`, unless stated.
